# 《爷爷的假牙笑了》TTS 剧本
【场景一：杯里的假牙】
[音色:冰糖]
（温暖讲故事语气）
爷爷把假牙泡在杯子里。杯子里的水，轻轻晃。
每天早上，爷爷都不太说话。他笑着，可嘴角是平平的。
「爷爷，你笑的时候，牙去哪儿啦？」他歪着头问。
爷爷不说话，只指了指桌子上的杯子。假牙在水里，安安静静地躺着。
他凑近杯子看。假牙也对着他，好像在悄悄笑。
【场景二：吹泡泡】
（温暖讲故事语气）
「噗。」他朝杯口吹了一口气。水面上，冒出一颗小泡泡。泡泡慢慢升到杯口，「波」地一下破了。
爷爷看见了，眼睛弯成了月牙。「哈，它也笑了。」他拍着小手。
【场景三：戴上假牙】
（温暖讲故事语气）
吃过早饭，爷爷把假牙戴回去。这回，嘴角是真正翘起来的。
爷爷端起茶杯。「咔。」假牙轻轻碰了下杯沿。
「来，爷爷笑一个。」他踮起脚尖。爷爷咧开嘴，假牙亮亮的，像含了颗糖。
「嘿嘿。」爷爷笑了，声音里带着一点点漏风。他也学着：「嘿嘿。」
【场景四：傍晚】
（温暖讲故事语气）
下午，爷爷坐在摇椅上，给他念图画书。念到好玩的地方，假牙跟着一闪一闪。
「咯咯咯。」爷爷笑出了声。他也跟着：「咯咯咯。」
爷爷故意把假牙取下来，对着他「呜呜」地假装说话。他笑得滚到了地毯上：「哈哈哈，爷爷没牙啦！」
