# 《瓶盖转三圈》TTS 剧本
【场景一：拧不开】
[音色:冰糖]
（轻快讲故事语气）
小熊举起小水壶。壶盖拧得紧紧的，像长在了壶上。「我想喝水。」他小声嘟囔。
他伸出两只手去转盖子。转呀转，盖子纹丝不动。「咦？」他愣住了，耳朵都竖了起来。
妈妈走过来，蹲下来。手指轻轻按住盖子顶。「先按，再转。」妈妈笑了笑。
【场景二：按了再转】
（轻快讲故事语气）
「咕咚。」小熊咽了下口水。他学着妈妈，用拇指死死按住盖顶。「按住了！」他用力点点头。
妈妈的手，包着他的小手，一起往右边慢慢转。「咔，咔，咔。」盖子松了一点点。
小熊自己来。按——转。按——转。手心里出了汗，他也顾不上擦。
【场景三：打开啦】
（轻快讲故事语气）
「咔啦。」盖子终于松开，轻轻跳了起来。水壶口，冒出凉凉的气。
「我打开啦！」他举起水壶，得意地晃了晃。水「叮咚叮咚」落进杯里。
喝一口。甜甜的，凉凉的，一直润到肚子里。
【场景四：教朋友】
（轻快讲故事语气）
小刺猬看见了，也拿来自己的小瓶子。「我教你。」小熊握着他的手，一起按，一起转。「咔啦。」小刺猬的盖子也开了。
「叮咚叮咚。」两个小杯子，一起倒水喝。以后每次喝水，他们都先按，再转。壶盖再紧，也难不倒他们。
