# 《名字掉在地上了》TTS 剧本
【场景一：掉名字】
[音色:冰糖]
（轻柔讲故事语气）
早上穿衣服的时候，他一低头。「吧嗒。」有什么东西从领口滑出来。掉在地上，滚了半圈才停。
他蹲下去看。地上躺着他的名字。摔成了两半——左边是「阿」，右边是「禾」。
他伸手去捡。名字却往桌子底下滚，躲进了凉凉的阴影里。
【场景二：叫不出名字】
（轻柔讲故事语气）
妈妈在厨房喊：「那个——小孩！吃饭了！」声音飘过来，落不到他身上。
他跑到幼儿园。老师在点名。念到他那个位置，老师顿住了。纸上一个字也没有。
「哗啦——」老师轻轻翻过那一页。「下一个。」老师说。
一整天，谁也叫不出他。点名册上，他的那一格空着。
【场景三：找回名字】
（轻柔讲故事语气）
放学路上，他把书包翻了个底朝天。文具盒底下，摸到硬硬的半块。「叮。」是「阿」。
第二天，在操场角落的草丛里。他找到了另外半块「禾」。露水「嘀嗒」落在上面。
他把两半拼在一起。刚合上——院子里、厨房里、楼上的人，同时喊起来：「阿禾——阿禾！」
【场景四：尾声】
（轻柔讲故事语气）
他站在原地，大声地应了一声：「哎！」
风把草叶吹得轻轻晃。他摸了摸胸口。名字，又长回去了。从今往后，他走路都挺直了背。
