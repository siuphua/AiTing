# 《影子被风吹走了》TTS 剧本
【场景一：风来了】
[音色:冰糖]
（轻柔讲故事语气）
傍晚，他牵着妈妈的手，慢慢往家走。地上的影子，也跟着他走。长长的，黑黑的。
一阵风过来。「呼——」影子被吹得歪了一下。「哎呀！」他叫出声。
路边的树叶，「沙沙沙」地响。风从叶子的缝里钻过去。
【场景二：挂上灯杆】
（轻柔讲故事语气）
风更大了些。「呼呼呼——」影子被卷了起来，像一片黑色的叶子。它飘到了路灯的杆子上。
「我的影子！」他仰着头。影子贴在灯杆上，一动不动。
妈妈笑了：「是风，把它挂上去啦。」他踮起脚，还是够不到。
【场景三：回来啦】
（轻柔讲故事语气）
又一阵风来了。「呼——」影子从灯杆上掉下来。它飘到他脚边，慢慢贴回地上。
「你回来啦。」他松了口气。他走一步，影子走一步。他跳一下，影子也跳一下。
他转个圈，影子也转个圈。「你学我呀。」他咯咯地笑。
【场景四：晚安】
（轻柔讲故事语气）
夜里，他躺在床上。窗外的风，还在轻轻吹。风把窗帘，「哗啦」吹起一角。
月光从缝里溜进来，落进他的手心。凉凉的，软软的，像捧着一小汪月光。
「晚安，影子。」他轻轻说。明天太阳一出来，影子就会悄悄回来，还跟在他脚边。
